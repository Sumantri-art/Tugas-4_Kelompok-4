# Eco-Smart Energy Hub 🌱⚡

## Pengenalan Aplikasi

**Eco-Smart Energy Hub** adalah aplikasi berbasis Flutter yang dirancang sebagai simulasi interaktif untuk mengontrol dan memantau kinerja turbin mikrohidro dalam mendukung penggunaan energi bersih dan berkelanjutan. Aplikasi ini mengangkat tema **SDG 7 (Affordable and Clean Energy)**, yaitu energi bersih dan terjangkau.

Aplikasi ini menyediakan tampilan panel kontrol yang memungkinkan pengguna berinteraksi langsung dengan komponen turbin melalui berbagai gestur pada layar. Pengguna dapat mengaktifkan atau menonaktifkan turbin dengan mengetuk kartu kontrol, mengaktifkan mode *Supercharged* dengan menekan dan menahan kartu, serta memindahkan posisi kartu dengan menggesernya menggunakan jari atau kursor.

Selain itu, aplikasi menampilkan informasi simulasi berupa daya listrik yang dihasilkan, efisiensi turbin, dan estimasi pengurangan emisi karbon dioksida (CO₂). Nilai-nilai tersebut berubah berdasarkan status turbin yang sedang dipilih. Aplikasi juga menyediakan tombol reset untuk mengembalikan posisi, status, dan penghitung interaksi ke kondisi awal.

## Fitur Utama

- **Kontrol Turbin:** Mengaktifkan atau menonaktifkan turbin melalui gestur tap.
- **Mode Supercharged:** Mengaktifkan mode peningkatan kinerja melalui gestur long press.
- **Interaksi Drag:** Memindahkan kartu kontrol dengan menggesernya pada layar.
- **Monitoring Simulasi:** Menampilkan daya listrik, efisiensi, dan estimasi pengurangan emisi CO₂.
- **Penghitung Interaksi:** Mencatat jumlah interaksi tap, long press, dan drag.
- **Reset:** Mengembalikan posisi dan status turbin serta penghitung interaksi ke kondisi awal.

## Teknologi yang Digunakan
- **Flutter** — framework untuk membangun antarmuka aplikasi.
- **Dart** — bahasa pemrograman yang digunakan dalam pengembangan aplikasi.
- **Visual Studio Code** — editor kode untuk mengembangkan dan menjalankan aplikasi.

## Tujuan Aplikasi
Aplikasi ini dibuat untuk menerapkan penggunaan gestur interaktif dalam pengembangan aplikasi Flutter sekaligus memperkenalkan konsep pemantauan energi terbarukan melalui simulasi turbin mikrohidro. Aplikasi ini juga menjadi sarana pembelajaran mengenai pentingnya energi bersih dan pemanfaatan teknologi untuk mendukung keberlanjutan lingkungan.

## Catatan
Aplikasi ini merupakan simulasi interaktif. Nilai daya, efisiensi, dan estimasi pengurangan emisi CO₂ yang ditampilkan merupakan nilai simulasi, bukan hasil pengukuran langsung dari perangkat turbin mikrohidro yang sebenarnya.
